## Vision

We, the Nullock Team, aim to provide the community with a modern, free, and open source alternative to paywalled tools like Burp Suite.

We envision a Web Hacking Suite that the community can freely clone, modify, and distribute — a platform built around freedom, transparency, and customization.

A tool that is so customizable and transformable that people can't help but love it.

Nullock is more than just a tool for the individual; it is a Web Hacking Suite that the FOSS and Cybersecurity community can build, improve, and evolve together.

## Overview

Nullock is a modern open-source Web Hacking Suite designed for penetration testers, bug bounty hunters, researchers, and cybersecurity enthusiasts.

The project focuses on delivering a highly customizable platform for web security testing without locking essential functionality behind expensive licenses or subscriptions.

Nullock aims to combine:

- Proxy interception
- Request manipulation
- Reconnaissance tooling
- Endpoint testing
- Workflow automation
- Extensibility

into one unified experience.

## Why Nullock?

Many modern cybersecurity tools have become increasingly restricted behind expensive subscriptions and commercial licensing.

Nullock exists to provide:

- Freedom to modify
- Freedom to self-host
- Freedom to contribute
- Freedom to learn

without sacrificing quality, performance, or user experience.

We believe powerful security tooling should be accessible to everyone.

## Installation

### Clone the Repository

```bash
git clone https://github.com/Bikebrainz/Nullock.git
cd Nullock
```

---

## Development Setup

### Install Dependencies

```bash
npm install
```

or

```bash
pnpm install
```

---

### Run Development Environment

```bash
npm run dev
```
