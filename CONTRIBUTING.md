## Contributing

---

We welcome developers/programmers, security researchers, bug testers, and all contributors of all experience levels.

Whether you're fixing bugs, improving the UI, writing plugins, or suggesting ideas — contributions are always appreciated.

1. Join the ![Discord](https://discord.gg/UYKFAjf9gk)
2. Create a fork
3. Get into contact with the team to begin working on Nullock
4. Ensure you have throughly tested your code 
5. Once you are ready and your fork is up-to-date with the main repo, submit a pull request for review

***Thank you for contributing to Nullock and becoming a part of the team!***
